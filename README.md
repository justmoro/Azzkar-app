# 🕌 حصن اليوم — أذكار الصباح والمساء

تطبيق ويب بسيط لأذكار الصباح والمساء، بتصميم زجاجي هادئ (Glassmorphism) مستوحى من التطبيقات الإسلامية الحديثة، مع:

- ✅ أذكار الصباح وأذكار المساء كاملة مع عدّاد تفاعلي لكل ذكر
- 🌗 تبديل تلقائي بين وضع الصباح (فاتح) والمساء (داكن مع نجوم) حسب الوقت
- 📿 سبحة رقمية (تسبيح) مع إمكانية تبديل الذكر وتصفير العداد
- 📊 حلقة تقدم (Progress Ring) تعرض عدد الأذكار المُنجزة اليوم
- 💾 حفظ التقدم تلقائيًا في المتصفح (localStorage) — بياناتك لا تُرسل لأي خادم
- 📱 تصميم متجاوب (Responsive) يعمل على الجوال والحاسوب
- 🕋 دعم كامل للغة العربية (RTL) بخطي **Amiri** و **Tajawal**

لا توجد أي تبعيات خارجية (Backend) — الموقع عبارة عن ملف HTML واحد فقط، يعمل مباشرة من المتصفح.

## 🚀 المعاينة محليًا

فقط افتح ملف `index.html` في أي متصفح، أو استخدم خادمًا محليًا بسيطًا:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح.

## 📤 النشر على GitHub Pages

1. أنشئ مستودعًا (Repository) جديدًا على GitHub، مثلًا باسم `azkar`.
2. ارفع محتويات هذا المجلد إليه:

```bash
git init
git add .
git commit -m "أول نسخة من تطبيق الأذكار"
git branch -M main
git remote add origin https://github.com/USERNAME/azkar.git
git push -u origin main
```

3. من إعدادات المستودع على GitHub: **Settings → Pages**
   - اختر **Source: Deploy from a branch**
   - اختر الفرع **main** والمجلد **/ (root)**
   - احفظ، وانتظر دقيقة، سيصبح الموقع متاحًا على:
     `https://USERNAME.github.io/azkar/`

## 🛠️ التخصيص

- **إضافة/تعديل الأذكار**: عدّل المصفوفتين `morningAzkar` و `eveningAzkar` داخل وسم `<script>` في `index.html`. كل ذكر عبارة عن كائن:
  ```js
  {text: "نص الذكر", note: "عدد المرات أو ملاحظة", target: 3}
  ```
- **الألوان**: عدّل متغيرات `:root` في بداية وسم `<style>` (مثل `--emerald`, `--brass`, `--dawn-1`...).
- **عبارات السبحة**: عدّل مصفوفة `tasbihPhrases`.
